更新方法
1. 解壓縮本 ZIP。
2. 將解壓後的檔案放進 chinese-review 儲存庫根目錄，與原 index.html 同一層。
3. 同名檔案選擇替換；assets 資料夾要合併，加入 assets/final-exam。
4. 保留網站其餘檔案，尤其既有課文、語基資料和其他 assets；不要刪掉整個舊網站。
5. 提交至 main，待 GitHub Pages 完成部署後重新整理；若仍見舊版，可用 Ctrl+F5。

此包不是完整網站，單獨放進空白儲存庫不能運作。
不需要更改 main 或 GitHub Pages 的根目錄設定。
本次只提供更新檔，未代你上傳 GitHub 或更改公開網站。
