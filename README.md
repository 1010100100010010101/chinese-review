## 更新 GitHub Pages

1. 解壓縮本 ZIP。上傳解壓後的檔案與 assets 資料夾，不能只上傳 ZIP。
2. 保持原有 main 分支；同名檔案以本包新版本取代，保留 assets 的子資料夾結構。
3. 若 GitHub 網頁提醒檔案數量上限，分兩批：先根目錄檔案，再上傳 assets 資料夾。
4. Settings → Pages：Deploy from a branch，main，/ (root)。
5. 部署完成後重新整理網站；如仍見舊內容，強制重新整理。

此為靜態網站，不用安裝套件或編譯。可直接開啟 index.html 試用；正式使用建議 GitHub Pages 或 Sites 網址。

## 使用說明

填寫及錯題紀錄留在同一瀏覽器。不同網址、裝置或瀏覽器的紀錄不會自動同步。模擬卷可以匯出作答備份。

朗讀使用瀏覽器和裝置的中文合成語音。請先按「測試聲音」；多音字與古文讀音應同時核對課本拼音。

模擬題為依上次題型自擬，並非老師原題。問答須自行按引文、解釋、扣題等評分點核對。
