# 字字記得｜中文大測溫習

繁體中文互動溫習網站，包含第一次及第二次測驗內容。

網站名稱：[https://1010100100010010101.github.io/chinese-review/](https://1010100100010010101.github.io/chinese-review/#study)
Chat-GPT網站：https://chinese-first-test-review.tzumingliu.chatgpt.site

## 功能

- 字詞及讀音詞卡、注音與拼音、詞義和重點字義。
- 錯別字填空、測驗與錯題重練。
- 課文背默、逐句譯文、點擊標記解析與意象圖片。
- 唐宋詞講義填空：62 題、110 空，附答案解析。
- 瀏覽器文字朗讀，含播放、暫停、停止、語速及語音測試。

## 開啟方式

這是靜態 HTML、CSS、JavaScript 網站，不需要安裝套件或建置。

在本資料夾執行 `python -m http.server 8000`，再開啟 http://localhost:8000 。

學習紀錄儲存在使用者目前瀏覽器的 localStorage，不會隨原始碼上傳。

文字朗讀使用裝置及瀏覽器可提供的中文語音；無可用語音時，畫面會顯示提示。

## 內容與維護

`index.html` 為入口；`assets/` 保留課文圖片、講義及記憶圖片。各資料檔與練習功能分開，方便後續編輯。

此匯出包含學習用講義及課本圖片，儲存庫經擁有人確認設為公開。未附開源授權，不表示第三方教材可自由再散布。
